Serveurs Ark
Aucun dossier sélectionné
✨ Créer un nouveau serveur Ark

Installe automatiquement un nouveau serveur dédié via SteamCMD, applique tes réglages, puis le lance. Nécessite que SteamCMD soit déjà téléchargé (panneau ci-dessus) et un dossier racine sélectionné.

Le niveau maximum par défaut d'un serveur Ark officiel est 30. Réglé ici sur 150 (le standard le plus courant sur les serveurs communautaires), via le paramètre OverrideOfficialDifficulty calculé automatiquement (niveau max ≈ 30 × cette valeur).

Note : SteamCMD n'affiche parfois aucune sortie pendant plusieurs minutes (il bufferise sa console quand elle n'est pas interactive) même quand le téléchargement avance normalement — fie-toi à l'indicateur de taille ci-dessus plutôt qu'à un écran vide.

SteamCMD

Outil en ligne de commande officiel de Valve, pratique pour installer ou mettre à jour un serveur dédié Ark (ou tout autre jeu) sans passer par le client Steam complet.

SteamCMD n'est pas encore installé.

En cas d'erreur du type « didn't shutdown cleanly » ou « missing configuration » lors d'une installation, les fichiers internes de SteamCMD sont probablement corrompus (souvent après un arrêt brutal). « Réinitialiser SteamCMD » supprime tout et permet de retélécharger une copie propre.

Raccourcis (remplissent le champ, à toi de valider) :
Sélectionne le dossier contenant tes serveurs Ark pour commencer.

« Setup Ark Server » applique en un clic la carte/session ci-dessous et les paramètres serveur courants, puis lance directement — pratique pour un serveur déjà installé, sans repasser par SteamCMD.

« Arrêter » ferme le processus. « Forcer l'arrêt » tue immédiatement tout l'arbre de processus (script + serveur) — utile si la console reste bloquée en demandant d'appuyer sur Ctrl+C (un signal qu'on ne peut pas simuler via une commande texte). Attention : un arrêt forcé ne laisse pas au serveur le temps de sauvegarder proprement.

Console

Le serveur doit être en cours d'exécution pour envoyer une commande. Note : contrairement à Minecraft, les serveurs Ark ne lisent généralement pas de commandes via cette console (ils utilisent le protocole RCON) — l'envoi peut donc n'avoir aucun effet selon ta configuration.
