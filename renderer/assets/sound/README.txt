Dossier des bruitages de l'interface (chargés par renderer/sound.js).

Déposez ici les 3 fichiers, avec exactement ces noms :

  - ButtonAccept.mp3      -> joué sur tous les boutons
  - PlayGameSound.mp3     -> joué sur le bouton « Jouer » des profils Minecraft
  - GameAndTabSelect.mp3  -> joué lors du défilement des jeux et du clic sur les onglets

Tant qu'un fichier est absent, le son correspondant est simplement ignoré
(aucune erreur, l'application reste utilisable).
